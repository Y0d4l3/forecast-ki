# 📈 Forecast KI

📌 A machine learning project using XGBoost for time series forecasting.  
Includes Jupyter Notebooks comparing models such as LightGBM and Random Forest, with performance benchmarks.

🛠️ **Tech Stack:** Python, XGBoost, LightGBM, RandomForest, Pandas, Scikit-learn, Jupyter  
📁 **Structure:** `notebooks/`, `models/`, `data/`, `forecast.py`
